Stage 10 GitOps & Argo CD Architecture

GitOps Reconciliation Architecture:

  • GitOps Repository (shopsphere-aws-scaling-gitops): The single source of truth for all Kubernetes desired state.
  • Argo CD Controller: Continuously reconciles live cluster state against the Git repository with automated drift correction.
  • Jenkins CI: Builds, tests, scans, pushes immutable images to ECR, and updates image tags in GitOps without directly touching the cluster.
  • Microservices: 4 decoupled services (frontend, product, order, user) running on Amazon EKS.

Zero Downtime Rollout:

  • RollingUpdate strategy with strict readiness/liveness health probes.
  • TargetGroupBinding dynamically routes ALB traffic to healthy NodePorts.
